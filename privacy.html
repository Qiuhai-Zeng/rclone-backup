Privacy policy

rclone-backup is a personal backup setup used only by its owner.

  • It requests only the drive.file scope, so it can access only the files it creates in the owner's Google Drive.
  • Files are copied directly between the owner's computer and the owner's Google Drive. No data is sent to any other server.
  • No data is collected, stored elsewhere, sold, or shared with anyone.
  • Access can be removed at any time at myaccount.google.com/permissions.
